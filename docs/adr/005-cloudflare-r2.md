# ADR-005 파일은 Cloudflare R2에 둔다

날짜 2026-10-12 · 상태 채택 · 관련 ADR-002

## 맥락

타임랩스(파일 하나 최대 100MB, 사람당 1GB)와 학습 샘플을 저장해야 한다.
`03-api.md` 9-1절이 "서버를 거치지 않고 presigned URL로 저장소에 바로 올린다"고 정했다. 그러니 저장소는 presigned URL을 줄 수 있어야 한다.
사용자가 자기 타임랩스를 보는 트래픽이 올리는 트래픽보다 많을 수 있다.

## 선택지

| 안 | 내용 | 걸리는 점 |
|---|---|---|
| A. Cloudflare R2 | S3 호환. 무료 10GB, 내려받기 전송 요금 없음 | 외부 서비스 하나 더. Cloudflare 계정 필요 |
| B. VM 디스크 + MinIO | VM 안에 S3 호환 서버를 띄움. 전부 한 곳 | VM 200GB 디스크를 Postgres와 나눠 쓴다. 전송량이 VM 회선을 탄다. 백업도 직접 |
| C. VM 디스크에 직접 + Spring이 파일 서빙 | 가장 단순 | presigned URL을 서버가 흉내 내야 하고, 파일이 서버를 거친다. API 설계와 어긋난다 |
| D. Supabase Storage | v1에서 써 봤다 | 무료 1GB. 타임랩스 몇 개면 찬다 |

## 결정

A. 로컬 개발은 MinIO (docker compose).

## 이유

presigned URL이 되면서 무료 용량이 쓸 만한 건 A뿐이다. 내려받기 요금이 없어서 타임랩스를 몇 번 다시 봐도 비용이 안 늘어난다.
B는 처음엔 끌렸다. 한 VM에 다 있으면 단순해 보인다. 그런데 Postgres 백업과 파일 백업을 둘 다 내가 챙겨야 하고, 파일 전송이 VM 회선을 먹으면 API 응답이 느려진다. 저장소는 바깥에 두는 게 서버를 가볍게 유지한다.
C는 API 설계를 거슬러서 버렸다. 설계에서 "파일이 서버를 거치면 안 된다"고 한 이유가 분명했다.
S3 API를 쓰므로 R2가 싫어지면 AWS S3, MinIO, Backblaze B2로 설정만 바꿔 옮길 수 있다. 코드는 AWS SDK for Java v2 하나다.

## 감수하는 것

- 외부 계정이 하나 는다 (Oracle, Cloudflare, AI API)
- 무료 10GB는 사람당 1GB 한도로 치면 10명분이다. 학습용 프로젝트에서는 충분하고, 넘으면 GB당 월 0.015달러다
- 로컬(MinIO)과 운영(R2)이 설정만 다르다. 설정 차이로 생기는 버그는 통합 테스트를 MinIO로 돌려서 잡는다

## 다시 볼 조건

저장 용량이 무료 한도를 넘어 비용이 생기거나, 파일을 변환(썸네일 등)하는 기능이 생겨 저장소 옆에 계산이 필요해질 때.
