# Zoner v2 요구사항

- 작성일: 2026-10-04
- 상태: 확정 (2026-10-04)
- 다음 문서: `02-domain-db.md` (도메인·DB 설계)

이 문서는 "무엇을 만드는지"만 정한다. 어떻게 만드는지(언어, DB, 서버 구조)는 여기서 정하지 않는다.
모든 기능은 위쪽의 문제·사용자·목표에서 이유를 찾을 수 있어야 한다. 이유를 못 찾는 기능은 뺀다.

---

## 1. 문제

공부한 시간은 어디서나 기록되지만, 그 시간에 실제로 집중했는지는 알기 어렵다.

기존 Zoner(v1)는 웹캠으로 집중도를 재고 리포트를 보여줬다. 다시 보니 약한 부분이 네 가지 있었다.

| 번호 | 약한 부분 | 설명 |
|---|---|---|
| P1 | 재기만 하고 끝남 | 리포트는 공부가 끝난 뒤에 나오고, 다음에 뭘 다르게 할지는 사용자가 알아서 해야 함 |
| P2 | 숫자를 믿기 어려움 | 얼굴만 봐서 교재를 보는지 휴대폰을 보는지 구분 못 함 |
| P3 | 카메라를 켤 이유가 약함 | 얼굴을 계속 비추는 부담에 비해 얻는 게 리포트 하나뿐 |
| P4 | 혼자 씀 | 안 켜도 아무도 모름. 며칠 쓰고 안 쓰게 됨 |

## 2. 사용자

주 사용자는 성인 수험생이다. 공시생, 자격증·고시 준비생, N수생처럼 혼자서 하루에 오래 공부하는 사람.

- 거의 매일, 하루 여러 시간 쓴다
- 책상에 PC나 노트북을 두고 웹캠으로 측정한다
- 이미 타이머 앱이나 캠스터디를 써 본 사람이 많다
- 매일 뭔가 채워지는 기록에서 성취감을 얻는다

다른 사람(대학생, 직장인)도 쓸 수는 있다. 다만 결정이 갈릴 때는 성인 수험생 기준으로 정한다.

## 3. 방향

두 가지 방향을 같이 간다.

A. 개인 코치
목표 설정 → 측정 → 달력 뱃지·연속 기록 → 돌아보기 → AI가 다음 계획 제안. 한 바퀴가 돌아야 한다. (P1을 푼다)

B. 얼굴 없는 캠스터디
같이 공부하는 방을 만들되, 영상은 보내지 않고 집중 상태만 서로 보인다. (P3, P4를 푼다)

P2(숫자 신뢰)는 공부 방식 선택과 판정기 교체로 따로 다룬다. (5.3, 5.9)

## 4. 지켜야 할 원칙

기능을 정할 때 계속 기준이 되는 것들이다.

1. 웹캠 영상은 기기 밖으로 나가지 않는다. 서버에는 판정 결과만 간다.
2. 사용자는 자기 판정 결과를 직접 고칠 수 없다. 순위와 뱃지가 걸려 있어서다.
3. 남에게 보이는 정보와 나만 보는 정보를 나눈다. 세부 사유(고개 돌림, 눈 감김 등)는 본인만 본다.
4. 사용자끼리의 상호작용은 긍정적인 것만 보낼 수 있다.
5. 서버는 판정이 어떤 방식으로 만들어졌는지 몰라도 된다. 판정기는 나중에 바꿀 수 있어야 한다.

## 5. 기능 요구사항

번호 순서가 만드는 순서다. 설계는 전체를 하고, 구현은 5.1부터 차례로 한다.

### 5.1 계정

| ID | 요구사항 |
|---|---|
| F-101 | 이메일과 비밀번호로 가입하고 로그인할 수 있다 |
| F-102 | 로그아웃할 수 있다 |
| F-103 | 닉네임을 정하고 바꿀 수 있다. 공개 방에서는 닉네임만 보인다 |
| F-104 | 탈퇴할 수 있다. 탈퇴하면 그 사람의 기록이 전부 지워진다 |

### 5.2 목표

| ID | 요구사항 |
|---|---|
| F-201 | 하루 순 집중 시간 목표를 정할 수 있다 (예: 6시간) |
| F-202 | 목표를 바꿀 수 있다. 바꿔도 지난 날의 달력 뱃지는 그대로 남는다 |

순 집중 시간은 집중으로 판정된 시간만 더한 값이다. 켜 놓은 시간이 아니다.

### 5.3 집중도 측정

| ID | 요구사항 |
|---|---|
| F-301 | 시작 전에 공부 방식을 고른다 (책·필기 / 화면 보기 / 인강 시청). 방식에 따라 판정 기준이 달라진다 |
| F-302 | 측정 중에는 5초마다 집중 여부를 판정한다 |
| F-303 | 집중이 무너지면 화면과 소리로 알린다 |
| F-304 | 일시정지할 수 있다. 쉬는 시간은 집중 시간에도 딴짓 시간에도 들어가지 않는다 |
| F-305 | 측정 중에 인터넷이 잠깐 끊겨도 기록이 날아가지 않는다 |
| F-306 | 세션을 끝내면 결과가 저장된다 |

### 5.4 리포트와 기록

| ID | 요구사항 |
|---|---|
| F-401 | 세션마다 리포트를 볼 수 있다 (순 집중 시간, 최장 집중 지속, 첫 이탈 시점, 전·후반 차이, 방해 원인 등 v1의 지표) |
| F-402 | 지난 세션 목록을 볼 수 있다 |
| F-403 | 세션을 지우면 휴지통으로 간다. 휴지통에서 되살리거나 완전히 지울 수 있다 |

### 5.5 달력 뱃지, 연속 기록, 업적 뱃지

뱃지는 두 종류로 나눈다.

| | 달력 뱃지 | 업적 뱃지 |
|---|---|---|
| 언제 | 하루에 하나, 달력에 남음 | 조건을 채운 순간 한 번 |
| 기준 | 그날 목표를 얼마나 채웠는지 | 누적 집중 시간, 높은 점수, 연속 기록, 칭찬 도장 등 |

| ID | 요구사항 |
|---|---|
| F-501 | 하루가 끝나면 그날 목표 달성 정도에 따라 달력 뱃지가 정해진다 |
| F-502 | 달력에서 날짜별 뱃지를 볼 수 있다 |
| F-503 | 목표를 며칠 연속으로 채웠는지 볼 수 있다 |
| F-504 | 조건을 채우면 업적 뱃지를 받는다. 같은 뱃지는 한 번만 받는다 |
| F-505 | 내가 받은 업적 뱃지 목록을 볼 수 있다 |

집중도 점수는 달력 뱃지 기준으로 쓰지 않는다. 짧게 하고 끝내는 사람이 유리해지고, 판정이 틀린 날에 억울한 기록이 남기 때문이다. 점수는 업적 뱃지에서만 쓴다.

### 5.6 AI 코치

| ID | 요구사항 |
|---|---|
| F-601 | 세션 리포트에 AI 조언이 붙는다. 수치는 서버가 계산하고 AI는 문장만 쓴다 |
| F-602 | 한 주가 끝나면 주간 돌아보기가 만들어진다 (목표를 채운 날, 못 채운 날의 공통점 등) |
| F-603 | 지난 기록을 바탕으로 다음 주 계획을 제안받는다 |
| F-604 | 내 기록을 아는 코치와 대화할 수 있다 |
| F-605 | AI 기능은 사람마다 하루 사용 한도가 있다 |

v1의 AI 채팅은 아무거나 물어보는 튜터였다. v2에서는 내 기록을 바탕으로 답하는 코치로 바꾼다.

### 5.7 스터디 방

| ID | 요구사항 |
|---|---|
| F-701 | 방을 만들 수 있다. 만들 때 공개/비공개와 정원을 정한다 |
| F-702 | 공개 방은 목록에서 찾아서 들어간다. 검색할 수 있다 |
| F-703 | 비공개 방은 초대 링크나 코드를 받은 사람만 들어간다 |
| F-704 | 방 안에서는 사람마다 지금 상태(집중 중 / 쉬는 중 / 자리 비움)와 오늘 순 집중 시간이 보인다 |
| F-705 | 방 안에서 오늘 순 집중 시간 순위를 볼 수 있다 |
| F-706 | 방장은 사람을 내보내고, 방 설정을 바꾸고, 방장을 넘길 수 있다 |
| F-707 | 다른 사람을 신고할 수 있다 |
| F-708 | 방에서 나갈 수 있다 |

영상, 음성, 채팅은 없다. 세부 판정 사유와 집중도 점수는 방에서 보이지 않는다.

### 5.8 칭찬 도장

| ID | 요구사항 |
|---|---|
| F-801 | 같은 방에 있는 사람에게 칭찬 도장을 줄 수 있다 |
| F-802 | 하루에 줄 수 있는 도장 수가 정해져 있다 |
| F-803 | 같은 사람에게는 하루에 한 번만 줄 수 있다 |
| F-804 | 받은 도장 수와 준 도장 수에 따라 업적 뱃지를 받는다 |

포인트와 실제 보상(기프티콘 등)은 넣지 않는다. 서로 찍어주기와 도배를 막으려고 F-802, F-803을 둔다.

### 5.9 학습용 데이터 수집

판정을 지금의 규칙 방식에서 직접 학습한 모델로 바꾸기 위한 준비다.

| ID | 요구사항 |
|---|---|
| F-901 | 동의한 사람에게서만 얼굴 좌표 흐름(영상이 아닌 숫자)을 모은다 |
| F-902 | 동의는 언제든 철회할 수 있다. 철회하면 모은 데이터를 지운다 |
| F-903 | 사용자가 판정이 틀린 구간을 표시할 수 있다. 이 표시는 순위·뱃지에 반영하지 않고 모델 개선에만 쓴다 |

## 6. 판정 방식 (두 단계)

| 단계 | 방식 | 시점 |
|---|---|---|
| 1차 | 사람이 정한 규칙 + 공부 방식 선택 | 이번 구현 |
| 2차 | 모은 데이터로 직접 학습한 모델 (+ 휴대폰 인식) | 서비스가 돌아가고 데이터가 모인 뒤 |

두 단계 모두 판정은 브라우저에서 한다. 서버가 받는 건 "5초마다 집중/딴짓 결과" 하나로 같다. 그래서 2차로 넘어갈 때 서버는 고치지 않는다.

## 7. 조건 (비기능 요구사항)

| ID | 항목 | 내용 |
|---|---|---|
| N-01 | 쓰는 기기 | PC 웹 브라우저 우선. 휴대폰에서는 기록과 달력 보기만 |
| N-02 | 영상 | 기기 밖으로 나가지 않는다 |
| N-03 | 개인정보 | 탈퇴하면 기록 전부 삭제. 학습용 데이터는 동의한 사람만, 철회 가능 |
| N-04 | 설계 기준 규모 | 가입자 1만 명, 동시에 측정 중인 사람 1,000명 |
| N-05 | 응답 속도 | 일반 요청은 대부분 0.3초 안 |
| N-06 | 방 상태 반영 | 상태가 바뀌면 2초 안에 같은 방 사람들 화면에 반영 |
| N-07 | 끊김 대응 | 인터넷이 잠깐 끊겨도 측정 기록을 잃지 않는다 |
| N-08 | AI 비용 | 사람마다 하루 사용 한도 |
| N-09 | 운영 비용 | 무료 또는 한 달 몇 만 원 안에서 실제로 배포 |
| N-10 | 저장소 | 새 저장소 `zoner-v2`. 기존 v1은 그대로 둔다 |

N-04의 숫자는 실제로 그만큼 올 거라는 뜻이 아니다. 숫자가 있어야 설계를 따질 수 있어서 정한 기준이다.
동시에 1,000명이 5초마다 판정을 보내면 서버에는 1초에 200건이 들어온다. 다 만든 뒤 부하 테스트로 확인한다.

## 8. 이번에 안 하는 것

| 항목 | 이유 |
|---|---|
| 관리자용 CCTV 모니터링 (학원, 스터디카페) | 쓰는 사람도 기술도 다르다. 다음 프로젝트로 따로 한다 |
| 포인트, 꾸미기 | 쓸 곳까지 같이 만들어야 하는 큰 기능. 뱃지로 먼저 시작한다 |
| 실제 보상 (기프티콘 등) | 비용이 들고 서로 찍어주기가 심해진다 |
| 방 안 채팅, 영상, 음성 | 공부를 방해하고 관리 부담이 크다 |
| 세션 영상 녹화 | 핵심이 아니다. 2차에서 학습용 데이터와 같이 다시 본다 |
| PDF 저장 | 수험생이 쓸 일이 거의 없다 |
| 요금제, FAQ, 가이드 페이지 | 첫 화면 하나로 줄인다 |
| 모바일 앱 | 측정은 책상 위 웹캠으로 한다 |
| 영상을 서버나 외부 AI로 보내서 판정 | 비용과 원칙 1번 때문에 안 한다 |

## 9. 구현 순서와 배우는 주제

| 순서 | 기능 | 백엔드 주제 |
|---|---|---|
| 1 | 계정 (5.1) | 인증, 비밀번호 저장, 토큰 |
| 2 | 목표, 측정, 리포트, 휴지통 (5.2~5.4) | 기본 저장·조회, 입력 검증, 지운 척하고 안 지우기 |
| 3 | 뱃지, 연속 기록 (5.5) | 통계 쿼리, 예약 작업, 중복 지급 막기 |
| 4 | AI 코치 (5.6) | 외부 API 연동, 스트리밍, 사용 한도 |
| 5 | 스터디 방 (5.7) | 실시간 통신, 권한, 동시에 들어올 때의 문제 |
| 6 | 칭찬 도장 (5.8) | 횟수 제한, 같은 요청이 두 번 와도 한 번만 처리 |
| 7 | 학습용 데이터 수집 (5.9) | 많은 양의 데이터 받기, 동의 관리 |

## 10. 뒤 단계에서 정할 것

요구사항 단계에서 일부러 안 정한 것들이다. 빠뜨린 게 아니라 정할 시점이 뒤다.

| 항목 | 정하는 시점 |
|---|---|
| 달력 뱃지 등급 기준 (몇 %부터 금·은·동인지) | 도메인 설계 |
| 업적 뱃지 목록 | 도메인 설계 |
| 하루에 줄 수 있는 도장 수 | 도메인 설계 |
| 방 정원 상한 | 도메인 설계 |
| 하루의 기준 시각 (자정인지, 새벽 공부를 전날로 칠지) | 도메인 설계 |
| 공부 방식별 판정 기준 값 | 구현 (v1 값에서 시작) |
| AI 하루 한도 숫자 | API 설계 |
| 신고가 들어온 뒤의 처리 방법 | 도메인 설계 |
| 언어, 프레임워크, DB, 배포 방식 | 구조·기술 선택 (ADR) |

## 11. 용어

| 용어 | 뜻 |
|---|---|
| 세션 | 측정을 시작해서 끝낼 때까지의 한 번 |
| 판정 | 5초마다 나오는 집중/딴짓 결과 한 건 |
| 순 집중 시간 | 집중으로 판정된 시간만 더한 값 |
| 집중도 점수 | 한 세션에서 집중으로 판정된 비율 |
